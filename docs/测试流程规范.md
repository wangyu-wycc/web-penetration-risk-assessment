# 企业Web渗透标准化测试流程
> 对标安全服务工程师日常工作流程
1. 前期对接：获取授权文档、确认测试IP、测试起止时间、明确禁止操作范围
2. 情报搜集：域名、端口、目录、组件版本、后台地址
3. 自动化初扫：使用扫描工具快速定位风险
4. 人工验证：逐一复现，排除误报
5. 漏洞取证：截图、记录Payload、复现步骤、影响范围
6. 风险分级
7. 撰写评估报告，一对一输出整改建议
8. 问题答疑，协助甲方完成漏洞复测

# 工作注意要点
1. 严格遵守授权边界，超出范围操作必须二次确认
2. 不进行破坏性测试（删数据、DoS攻击）
3. 报告语言面向甲方，通俗易懂，不只罗列漏洞原理
