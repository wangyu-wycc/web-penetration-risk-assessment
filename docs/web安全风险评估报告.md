# Web应用安全风险评估报告
## 1 项目概述
本次评估模拟乙方安全服务项目，针对Web应用系统开展黑盒渗透测试，识别系统存在的安全漏洞，划分风险等级，输出可落地的安全整改建议，参考等保2.0、CVSS3.1评分标准开展评估。

## 2 测试环境
测试靶标：DVWA、WebGoat
测试环境：本地虚拟机搭建，内网环境
测试工具：Nmap、Burp Suite、Sqlmap、Dirsearch

## 3 测试范围与流程
1. 信息收集：端口扫描、目录爆破、中间件识别、页面指纹探测
2. 漏洞探测：自动化扫描 + 人工手动验证
3. 漏洞复现：完整记录利用步骤、影响边界
4. 风险定级：高危、中危、低危
5. 整改方案编写
6. 整体安全总结

## 4 漏洞汇总
### 4.1 高危漏洞
1. SQL注入漏洞
- 风险描述：输入点未做过滤，攻击者可构造SQL语句读取数据库数据
- 复现路径：页面参数拼接SQL语句，无预编译防护
- 整改建议：使用参数化查询，过滤特殊字符，部署WAF规则

2. 文件上传漏洞
- 风险描述：后端仅校验文件后缀，可绕过上传脚本文件，获取服务器权限
- 整改建议：校验文件文件头、限制上传目录执行权限、重命名上传文件

### 4.2 中危漏洞
1. XSS跨站脚本漏洞
- 风险描述：页面直接渲染用户可控输入，可执行JS脚本窃取Cookie
- 整改建议：前端输出编码、后端输入过滤、开启HttpOnly Cookie

2. 弱口令风险
- 风险描述：账号使用简单密码，易被暴力破解
- 整改建议：启用复杂度密码策略，登录失败锁定机制

### 4.3 低危漏洞
1. 敏感目录泄露
2. Web服务版本信息暴露

## 5 整体安全总结
靶场系统存在多处高危Web漏洞，缺乏输入校验、权限管控不足。正式业务系统需要从代码开发、服务器配置、安全设备防护多层加固，定期开展常态化渗透测试与漏洞扫描。
