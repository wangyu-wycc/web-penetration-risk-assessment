# Web渗透测试与风险评估项目
> 模拟乙方安全服务标准化渗透评估流程，区分CTF竞赛思路与企业安全服务工作，适配安全服务工程师实习简历项目

## 🎯 项目目标
复刻政企正规Web应用风险评估全流程：遵循渗透测试授权规范，依次完成信息收集、漏洞探测、人工验证复现、风险等级判定，输出可落地安全整改方案，最终产出标准化《Web应用安全风险评估报告》。
通过靶场实操掌握Web漏洞原理、攻击链路、风险研判，建立企业安全服务思维。

## 🧪 实验环境
| 分类 | 详情 |
| ---- | ---- |
| 靶场环境 | DVWA、WebGoat（本地虚拟机内网部署，无对公网络测试，全程合规） |
| 测试模式 | 黑盒人工渗透，拒绝单一依赖自动化扫描结果 |
| 工具清单 | Nmap、Burp Suite、Sqlmap、OpenVAS、Linux基础排查命令、蚁剑 |

## 📋 完整实施流程
1. **前期准备**：模拟签订渗透测试授权委托书，明确测试边界、禁止操作范围，划定测试时间窗口
2. **信息收集**：域名探测、端口扫描、目录爆破、中间件指纹识别，梳理全部可控输入点
3. **漏洞探测**：自动化扫描工具初筛 + 人工Payload验证，剔除工具误报
4. **漏洞复现**：完整记录每一步骤、页面现象、影响边界，全程截图留存取证
5. **风险分级**：参照CVSS3.1评分标准、等保2.0规范划分高危/中危/低危漏洞
6. **方案输出**：针对每一条漏洞编写开发、服务器双维度可落地修复建议
7. **汇总交付**：整合所有内容，生成正式《Web应用安全风险评估报告》

## ⭐ 重点研究方向（面试高频讲述点）
1. **企业渗透测试和CTF竞赛的核心区别**
2. **渗透测试合规风险、授权边界的重要性**
3. 主流Web漏洞原理分析，结合业务思考次生风险
4. 标准化安全评估报告撰写思路
5. 漏洞风险定级逻辑与落地整改方案设计
