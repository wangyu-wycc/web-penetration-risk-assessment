# Web渗透测试与风险评估项目
> 模拟乙方安全服务标准化渗透评估流程，区分CTF竞赛思路与企业实战安全服务工作，适配安全服务工程师实习简历项目。

## 🎯 项目目标
复刻政企项目正规Web应用风险评估全流程：遵循渗透测试授权规范，完成信息搜集、漏洞探测、人工验证复现、风险等级判定，输出可落地的安全整改方案，最终产出标准化安全评估报告。

## 🖥️ 实验环境
靶场环境：DVWA、WebGoat（本地部署，无对公网未授权测试，全程合规）
工具清单：Nmap、BurpSuite、Sqlmap、OpenVAS、Linux基础排查命令

## 📋 完整实施流程
1. 前期准备：模拟签订渗透测试授权委托书，明确测试边界、禁止操作范围
2. 信息收集：子域名探测、端口扫描、目录爆破、中间件版本识别
3. 漏洞探测：自动化扫描 + 人工手动验证（拒绝仅依靠工具扫描结果）
4. 漏洞复现：完整记录复现步骤、现象、影响范围，截图留存证据
5. 风险分级：参照CVSS、等保2.0标准划分高危/中危/低危风险
6. 方案输出：针对每一条漏洞编写可落地修复建议
7. 汇总输出：生成正式《Web应用安全风险评估报告》

## 📌 重点研究方向（面试高频讲述点）
1. 企业渗透和CTF的核心区别
2. 渗透测试合规风险、授权边界重要性
3. 常见Web漏洞原理与业务侧风险思考
4. 安全评估报告撰写思路
